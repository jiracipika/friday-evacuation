## Requirement-by-requirement

1. Full input suppression — `_input()` now calls `get_viewport().set_input_as_handled()` for every event while active; the only exception is `ui_cancel` in the ERROR state, which triggers BACK and marks handled (Escape can no longer leak to the menu underneath, and `_backed` guards duplicate keyboard activation). Previous GUI focus owner is captured in `_ready()` (viewport `gui_get_focus_owner()`) and restored on dismissal/BACK via `_restore_focus()` (only if still valid and in tree). Regression: a `Sentinel` node (counts every `_input` it receives) is added to root BEFORE the overlay mounts to reproduce real input order (later root children get `_input` first); real `Input.parse_input_event()` key/action/mouse events are then fed. Result: 0 leaked events, Escape while loading neither leaks nor dismisses the overlay.

2. Fade removed — `DISMISS_FADE_TIME` and `_dismissing`/`_fade_elapsed` machinery deleted. On success: `remove_from_group(GROUP)` then `queue_free()` immediately — no opaque overlay lingering over usable UI, no stale duplicate lock. Test asserts the source constant is gone and the lock clears within one frame of detected readiness.

3. Frame timing — added `_wait_drawn_frame()`: awaits `RenderingServer.frame_post_draw` in graphical mode, `process_frame` headless fallback (no hangs). Used BOTH before the first `ResourceLoader.load_threaded_request` (so the request follows an actual overlay draw, not just a process tick) and before `change_scene_to_packed` (so `PREPARING OFFICE` actually renders for a frame before instantiation).

4. Safe swap/readiness — `_swap_scene()` stores `get_instance_id()` of the outgoing scene instead of holding a Node that `change_scene_to_packed` frees; readiness loop compares instance IDs. If the target exposes `is_loading_complete()` it is polled until true (loop breaks immediately if the tree is paused, preserving any pre-match pause); otherwise `is_node_ready()`. `READINESS_TIMEOUT_S = 10.0` bounds the wait; on timeout the overlay shows an actionable error ("The office did not finish opening. Press BACK, then try again.") with lock/BACK/retry intact — no indefinite loop if the scene disappears (`current_scene == null` is tolerated, not fatal). Error lock: `_go_back()` releases the group and frees; `show_loading()` accepts a fresh request afterward (failed-then-valid retry test).

5. Tests — all checks exercise real SceneTree transitions (`current_scene` actually swaps). Kept and re-verified: absent path, non-PackedScene target, duplicate request, error-back (now via a real parsed Escape key), retry. Added: pending-readiness fixture, keyboard blocking (sentinel + parse_input_event), fade-removal source check. Runner `/tmp/fe_verify.py` enforces a 180 s subprocess timeout and inspects combined stdout+stderr for `SCRIPT ERROR` / `Parse Error`. Expected negative fixtures (ResourceLoader errors for bad path / non-PackedScene) logged as handled engine messages only — no unhandled script errors.
