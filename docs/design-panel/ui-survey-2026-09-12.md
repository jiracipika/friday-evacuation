## Splash (menu/f00000041)
- Solid orange full-screen, tiny pale "FRIDAY 5PM:" + big brown "EVACUATION" dead-center, "CLICK TO START" hint.
- Flat single-color, no art, feels like a loading error not a title card. Brown-on-orange fails contrast.

## Main menu (menu/f00000060, 1280x720)
- Left: small grey "F5P" wordmark top-left; huge orange "FRIDAY 5PM: EVACUATION" (looks like stretched default font, all-caps); amber tagline text sits directly on the 3D skyline backdrop with no panel — low contrast.
- Middle: vertical stack of 4 mode cards, dark navy rounded rectangles, orange left accent strip, centered white title, tiny green top-right status tag. Cards look flat/undersized relative to screen; Hauled card visibly taller than others (title + same long subtitle repeated: "CO-OP PHYSICS DELIVERY • DELIVERY PLAYABLE" — duplicates the tag).
- Utility buttons row (SETTINGS / HOW TO PLAY / QUIT) squeezed as small dark pills under the cards.
- Right: character/roster preview card ("YOUR RIDE") with a plain blue office chair on a yellow disc, "Rider & chair update live" caption. Looks placeholder-ish.
- Background: purple/orange dusk skyline silhouette — best-looking element, but menus don't react to it (no parallax, cards just float).
- Overall: stock Godot default font everywhere, no typographic hierarchy beyond size, left column vs right column visually disconnected, lots of dead space bottom-left.

## Gameplay + HUD (evac_start, 1280x720)
- Top center: "FLOOR 1   2:00   RACE" — white/gold/green plain text, no backing, thin banner strip.
- Below it: amber goal banner "GOAL 1/4 — FIND THE ELEVATOR • GLASS TUBE AT THE EDGE" — small caps text directly over 3D ceiling lights, gets lost.

- Bottom-right: dark card with "BOOST READY [SPACE]" (amber text), thin amber bar, "Q SABOTAGE" row. Fine but plain.
- Center: player name labels "Player1"/"GHOST" float over the chair; small red ice-cube trap icon in a square outline; a banana peel pickup (large yellow low-poly blob) dominates the lower-right of the 3D view.

- Overall HUD verdict: functional but bare — default font, flat dark cards, no visual identity tying it to the menu, no countdown "3-2-1-GO" big center moment visible in captures, controls overlay was suppressed.

## Results (finish/f00000089)
- Semi-transparent grey rectangle center screen with "NO WINNER" in orange, then plain white "REMATCH" and "MAIN MENU" texts (buttons barely styled — look like labels).
- Stats the code writes (TOP SPEED / TRAPS HIT) not visible in capture — panel is nearly empty, no styling, no medal/confetti/fun. By far the weakest screen.
- HUD stays visible under it (0 km/h, BOOST READY) which adds clutter.

## Pause (pause/f00000069)
- Dark backdrop dims game; centered rounded panel with 2px orange border, "PAUSED" big orange, "ESC to resume" small grey, RESUME / SETTINGS / QUIT TO MENU stacked buttons (dark with white text, focus outline on RESUME).
- This is the best-styled screen (matches dark-navy + orange accent identity) — but plain: no icons, no match stats, button hover/focus states minimal.

## Settings (settings/f00000079)
- Same centered panel style (orange border, dark navy bg). Rows: graphics-quality dropdown, master/music/SFX sliders, screen-shake toggle, back button.
- Small default-font labels; sliders are unstyled thin default Godot grabbers; no section grouping, no header beyond "SETTINGS"; feels like a debug panel, not a game menu.

## Cross-cutting problems (for design brief)
1. Default Godot font everywhere; no display font, no type scale.
2. Two competing panel languages: menu cards (flat navy, accent strip) vs HUD cards (plain dark) vs pause panel (rounded orange border). No shared component style/spacing.
3. Orange-on-dark works but is applied inconsistently (accent strips, borders, text, fills all mixed).
4. Results screen is barren and joyless — needs celebration, stats layout, button styling.
5. Splash screen looks broken (flat orange, bad contrast).
6. HUD has no hierarchy: all elements same visual weight, text floats over bright 3D areas.
7. Menu screens don't use the (good) dusk skyline art; no parallax/motion.
8. Dense pre-match screen: clipped text, cramped modifier grid, redundant titles.
9. Minimap nearly unreadable (too dark, tiny dots, no goal marker visible).
10. No microcopy/voice consistency; comedy tone of the game doesn't come through anywhere in the UI.
