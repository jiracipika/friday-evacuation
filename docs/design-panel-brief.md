# Friday Evacuation — design panel brief

User request: continue improving the Godot game and create a visual panel that can serve as its design template. Keep implementation economical using GLM 5.3 Flash with parent art direction. This is a design-selection deliverable first, NOT approval to replace the gameplay visual identity yet.

## Existing context and assets
Private project Friday 5PM: Evacuation, Godot 4.7.1 GL Compatibility. Read docs/GLM-NEXT-SLICE.md, scripts/UITheme.gd, scripts/OfficeDressing.gd and project.godot selectively. Existing orange identity #ff9a1a, dark chrome #0a0a0f and #1c1c2e. Main mechanic is racing an office chair through a chaotic office to escape work. Four stacked floors, elevators, desk obstacles, coffee boosts and mischievous sabotage. Do not redesign physics, navigation, networking, camera or collisions for a design board. Do not change engine or install Blender. Existing menu icon/logo asset can be used if present; do not invent third-party branding.

## Audience, purpose and format
Audience: friends playing a readable, funny, energetic co-op/party game on desktop and mobile, including modest MacBook hardware. Panel viewed on a laptop with responsive phone support. Deliver docs/design-panel/index.html as an offline-capable browser design workbench, plus three distinct standalone direction HTML pages. No npm app scaffold or backend. Prefer shared small CSS/JS files over dependencies. Every direction must be visibly rendered, not only described. Include a usable HUD mockup, palette swatches with exact hexadecimal values, material/shape examples, lighting recipe, world signage examples and an actionable Godot translation list. Clearly mark all mockup race values as illustrative, not actual game telemetry. Do not pretend an HTML mockup is a Godot render.

## Three direction anchors
A: AFTER-HOURS DUSK (parent recommendation). Warm apricot desk pools, petrol/teal shadow masses, muted plum dusk beyond the windows, cream paper and walnut furniture, orange primary CTA. Cinema-like lighting hierarchy but cheerful office comedy, not horror. Wide cinematic world-preview area with restrained peripheral HUD. Rounded but weighty signage and a strongly legible floor destination. Signature: an employee time-card/clock-out motif. Keep the chair silhouette readable against the floor. Sunset contrast must not require bloom/SSAO.
B: TOYBOX OFFICE. Tactile chunky geometry, milky mint and butter-cream, ink outlines in the interface, coral controls. Oversized coffee cup and blunt forms, short playful labels. Arrange the board like a physical prop/material specimen sheet rather than the cinematic A composition. Rounded bevel-like shapes and broad flat surfaces; no visual noise, no rainbow-everywhere treatment. Signature: sticker-like hazard signs and springy but reduced-motion-aware interaction. Explain that properly beveled hero assets can later be generated as Godot ArrayMesh or imported glTF, while remaining in Godot.
C: CORPORATE EMERGENCY. Swiss-like industrial signage interpreted for comedic escape. Charcoal, safety orange, bone white, sparing signal green. Condensed bold display type, tabular countdown, asymmetric strong rule/grid composition, floor numbers and route arrows. Not generic cyberpunk/neon. Signature: deliberately over-serious workplace safety posters about ridiculous chair racing. Broad structural patterns, never high-frequency stripes across gameplay floor surfaces.

## Visual truth and constraints
Use existing real game screenshot if retrievable locally or capture real Godot frames with a temporary SceneTree harness suppressing PreMatchModal. A real baseline screenshot should be explicitly labeled CURRENT GODOT BUILD. If no screenshot obtainable, say so plainly; design panels should still be complete with rendered interface/material/signage specimens, not fabricated gameplay images. CSS/SVG is appropriate for abstract material tokens and interface symbols, not pretending to be a real game screenshot. No image-generation API spend necessary.

Readability: body at least 14px, annotations at least 12px; no horizontal overflow at 390px; keyboard-accessible direction selection, visible focus, reduced-motion support. Favor an oversized expressive title paired with practical readable body text. All controls must work: switch direction, toggle HUD sample state (READY/BOOST), and copy/export a concrete token recipe using clipboard with fallback for file://. Persist selected preview locally, but label preview selection as non-binding: user approval in conversation is still needed before game-wide restyle.

## Godot translation constraints
Keep GL Compatibility and low quality viable. No new real-time shadow-casting lights for the template; exploit shared roughness/albedo materials, existing culled lights, emissive signs, silhouette and contrast. Ceiling attachments cast_shadow OFF. Cached materials must be duplicated before per-instance animation. Props non-colliding unless coordinated with collision changes. Existing slab top is floor center +0.1m: ground dressing must sit above it. Respect 3-floor elevator coordinate invariants, culling registration and checkpoint routes. Desktop and landscape mobile HUD use shared tokens; center of gameplay remains clear.
